# Prepare for Section 3

Prepare a personal approval tracker before class. The exercise uses one manual **Request title** input, so you do not need another Form or any document uploads.

1. Download [document-approval-tracker.xlsx](/downloads/document-approval-tracker.xlsx). Upload it to your own OneDrive for Business training folder using the confirmed training account.
2. Open it and confirm worksheet **Approvals**, table **DocumentApprovalsTable**, and the exact four headers **ApprovalId**, **RequestTitle**, **Status**, **Decision**. One blank starter row is intentional. Do not rename the table or enter sample results into the live tracker.
3. Close the workbook's editing window before running the flow. View or refresh results without editing while a run is active. Use one workbook per learner and one test run at a time.
4. Confirm with the instructor that your account can use Approvals, create a cloud flow, read/write this workbook and send/receive Outlook email. Select the agreed environment. Approvals may require environment provisioning by an authorised administrator; do not create an environment or start a trial yourself.
5. Read [the supplied review briefs](/downloads/document-approval-sample-inputs.txt). The approval Details will contain both fictional versions; the one input identifies which version you are reviewing. No real business documents are needed.

> **Access:** Approvals, Excel Online (Business) and Office 365 Outlook are Standard connectors. The organiser must confirm the required licences, provisioning, permissions and actual learner access. A downloaded workbook alone does not prove readiness.

The [expected-results workbook](/downloads/document-approval-expected-results.xlsx) contains visibly fictional IDs for comparison only. Do not connect your flow to it. Keep the [reset workbook](/downloads/document-approval-tracker-reset.xlsx) available for a clean start.

Proceed to [Exercise 3](../exercises/03-document-approval.md). If access is unavailable, follow the instructor's demonstration and record which hands-on check remains unperformed.
